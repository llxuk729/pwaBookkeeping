# 🥟 智能早点记账 (AI Bookkeeping PWA)

一个专门为早餐店/家庭记账场景打造的**纯本地、高隐私、强智能**的渐进式 Web 应用 (PWA)。
 
<a href="https://llxuk729.github.io/pwaBookkeeping/" rel="noopener noreferrer" target="_blank">在线地址</a>

基于现代 Web 技术栈构建，它不仅支持传统的键盘输入，还集成了浏览器原生的语音识别，并且突破性地在前端 Web Worker 中直接运行**大模型 (Transformers.js)** 进行自然语言的语义理解和自动分类，整个过程不需要向任何外部服务器发送您的隐私数据。

## ✨ 核心特性

- **🤖 高性能规则引擎 + AI辅助**：
  - **Tokenizer**: 基于 正则表达式 的中文分词，精准识别商品名称和金额边界
  - **金额FSM状态机**: 自定义有限状态机，支持"12块4毛6", "两块五", "¥35", "4元5角"等多种中英文混合格式，准确率>95%
  - **智能分割器**: 自动识别多商品边界，支持逗号分隔、空格分隔和无分隔符的智能解析（如"豆腐3块5可乐2块"）
  - **Schema验证**: 使用 valibot 进行轻量级数据结构验证，确保数据完整性和类型安全
  - **AI按需加载**: Transformers.js 仅在需要分类建议时通过 Web Worker 异步加载，不阻塞核心记账流程
- **🎙️ 智能语音输入**：
  - **Web Speech API**: 轻量级原生语音识别，无需下载模型，零额外依赖
  - **平台支持**: Windows/Android 浏览器（非 PWA 模式），按住说话松开即完成识别
  - **实时反馈**: 支持中间结果（interim results）显示，让用户看到识别过程
  - **隐私保护**: 所有处理在浏览器端完成，音频数据不会发送到外部服务器
- **🔒 绝对的隐私安全**：
  - **纯本地运行**: 所有数据使用 IndexedDB (Dexie.js) 保存在浏览器本地，无需后端 API
  - **离线可用 (PWA)**: 支持添加到手机桌面，无网络环境下也能顺畅记账和进行 AI 识别
  - **零数据外传**: 语音识别、文本解析、AI 分类全部在本地完成，无任何数据发送到云端
- **🎨 现代流畅的用户体验**：
  - **浅色/深色模式**: 支持系统主题自动切换，也可手动切换
  - **玻璃拟态设计**: Glassmorphism UI 风格，精美的交互动画和视觉反馈
  - **实时预览**: 输入后立即显示解析结果，支持手动调整类型、分类、金额等字段
- **🛡️ 坚固的数据保护墙**：
  - **跨月备份提醒**: 每月首次打开应用时智能提醒备份上月数据
  - **安全防作死升级**: 版本升级前强制后台自动导出 JSON 完整备份，确保数据安全
  - **多重导出格式**: 支持 CSV（Excel兼容）和 JSON（完整备份）两种导出格式
- **📊 完整的账单管理**：
  - **多维度统计**: 今日支出、本月支出、分类统计图表（Chart.js）
  - **动态分类**: 支持早餐店专属分类（黄小米、黑米、小笼包等），可自定义增删改
  - **一键导出**: 支持按时间范围筛选并导出为 Excel 可读的 CSV 文件

## 🛠️ 技术栈

- **核心框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **解析引擎**: 
  - **中文分词**: 自定义正则表达式分词
  - **金额FSM**: 自定义状态机,支持中英文混合金额表达
  - **数据验证**: `valibot` (轻量级schema验证)
- **AI辅助** (可选): `@xenova/transformers` (按需加载,用于分类建议)
- **语音识别**: Web Speech API (SpeechRecognition) - 浏览器原生能力
- **本地数据库**: Dexie.js (基于 IndexedDB)
- **状态管理**: Pinia
- **PWA支持**: `vite-plugin-pwa`

## 🚀 快速开始

### 安装依赖
```bash
npm install
```

*(注意: 语音识别使用浏览器原生 Web Speech API，无需下载任何模型文件)*

### 运行开发服务器
```bash
npm run dev
```

### 构建与打包
```bash
npm run build
```
打包后生成的 `dist` 文件夹即为产物。

## 🎙️ 语音识别说明

### 支持的平台
- ✅ **Windows 浏览器** (Chrome, Edge 等)
- ✅ **Android 浏览器** (Chrome, Samsung Internet 等)
- ❌ **Mac / iPhone**: 不支持 Web Speech API
- ❌ **PWA 应用**: Android/iOS PWA 模式下无法获取麦克风权限

### 使用提示
在不支持语音识别的设备上（如 Mac、iPhone 或 PWA 应用），输入框下方会显示提示文字，建议使用系统键盘自带的语音输入功能。

### 技术实现
- 使用浏览器原生的 `SpeechRecognition` API
- 无需下载任何模型文件
- 轻量级实现，零额外依赖
- 所有处理在浏览器端完成，保护隐私
